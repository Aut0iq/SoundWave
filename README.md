# SoundWave

Приложение, которое слушает микрофон и превращает голос или гитару в музыку: ноты, аккорды, MIDI для DAW, битбокс-барабаны и автотюн. Работает в браузере на ПК.

## Запуск

Нужен [Node.js](https://nodejs.org) 20+.

- Двойной клик по `start.bat` (при первом запуске сам поставит зависимости и откроет браузер), или
- в терминале: `npm install`, затем `npm run dev` и открыть http://localhost:5173

Браузер: **Chrome или Edge** (в них есть Web MIDI). Нажми «Включить микрофон» и разреши доступ.

## Вкладки

**Голос → MIDI.** Поёшь или играешь, приложение определяет ноту и сразу играет её выбранным инструментом и/или отправляет в MIDI-порт.
- Привязка к тональности (фальшивые ноты подтягиваются к ладу), свой набор нот по кнопкам.
- Аккорды из одной спетой ноты: трезвучия и септаккорды в тональности, мажор, минор, квинта, sus и др.
- Pitch bend: «Удержание» (нота стоит ровно, пока не уведёшь голос) и «Следование» (повторяет каждое движение).
- Сила нот по громкости, громкость → CC, тембр (гласные) → CC.
- Автоопределение тональности по тому, что ты спел.

Всё спетое на этой вкладке само складывается в **дубль**: его можно сохранить прямо в FL Studio, отправить в «Студию», скачать как MIDI или перетащить мышью.

**Битбокс.** 8 падов. Нажми «Обучить», сделай свой звук 5–8 раз, нажми «Готово». Дальше «бф», «тс», «пш» играют бочку, хэт, малый и т.д. и уходят в MIDI на канал барабанов.

**Студия.** Запись с метрономом и отсчётом, многодорожечность, пианоролл-редактор (перетаскивание, длина, удаление, транспонирование), квантизация, «чистка» случайных нот. У каждой дорожки свой инструмент и режим звучания: инструмент, оригинальный голос, голос с автотюном или их смесь. Экспорт в MIDI (можно перетащить прямо в DAW) и WAV. Проект сохраняется в браузере автоматически.

**Автотюн.** Коррекция голоса к нотам тональности в реальном времени (слушать только в наушниках) с регулировкой скорости (от «робота» до естественного), силы и смеси. Для записанных дорожек автотюн применяется без изменения оригинала.

## Инструменты

- 19 реалистичных (рояль, гитары, бас, скрипка, виолончель, струнные, хор, труба, саксофон, флейта и др.) — сэмплы FluidR3 GM скачиваются один раз и кэшируются в браузере.
- 10 синтезированных: работают без интернета (если сэмплы недоступны, играет похожий синтезатор).

## FL Studio

Кнопка «Настроить связь с FL Studio» слева проводит по шагам и делает за тебя всё, что можно:

1. Запускает **loopMIDI** (виртуальный MIDI-кабель; нужен порт «loopMIDI Port»).
2. Ставит **скрипт SoundWave** в `Documents\Image-Line\FL Studio\Settings\Hardware\SoundWave`.
3. Подключает выход и вход MIDI SoundWave к loopMIDI.
4. Один раз в FL: Options → MIDI settings → Input «loopMIDI Port»: Controller type **SoundWave** (Enable включится сам), Port 1; Output «loopMIDI Port»: Port 1.
5. При первой записи FL спросит «What would you like to record?»: отметь «Don't show this in the future» и выбери **Notes and automation**.

После этого:
- ноты из SoundWave играют выбранный в FL инструмент, а «● Запись в FL» включает запись в FL — ноты пишутся прямо в пианоролл;
- «▶» и «■» управляют воспроизведением FL;
- темп берётся из FL, а при старте записи в FL начинается новый дубль;
- «Сохранить в FL Studio» кладёт дубль в браузер FL: Recorded → SoundWave.

## MIDI в другие DAW (Ableton, Reaper…)

1. Установи бесплатный [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html) и создай порт.
2. В SoundWave: «Подключить MIDI» → выбери этот порт как выход.
3. В DAW включи этот порт как MIDI-вход и поставь на дорожку любой синтезатор.

## Ограничения

- Распознаётся одна нота за раз (мелодия), аккорды на гитаре — нет.
- Минимальная задержка «голос → звук» около 50–90 мс в зависимости от режима «Задержка».

## Разработка

```
npm test          # тесты: высота тона, ноты, устойчивость к дрожанию голоса, автотюн, аккорды, битбокс, MIDI, связь с FL

npm run build
```

Весь код написан с нуля на открытых алгоритмах: YIN (определение высоты тона), TD-PSOLA (автотюн), Karplus–Strong (синтез струн), профили Крумхансла (определение тональности).
